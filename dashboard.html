Algorithm: AMDA

Adaptive Multi-parameter Decision Algorithm

Analyses 5 weighted parameters (water level, flow rate, rate of change, days of supply, historical pattern) with temporal context to generate a composite score (0–100) mapped to 5 states: Critical High (≥90%), High (70–89%), Normal (30–69%), Low (20–29%), Critical Low (≤19%). Provides predictive analytics and specific actionable recommendations.

⚡ Voltage Divider — HC-SR04 ECHO Pin

The HC-SR04 outputs 5V on the ECHO pin. The ESP32 GPIO is 3.3V-tolerant only. Use a simple resistor divider:

HC-SR04 ECHO ──[1kΩ]──┬──[2kΩ]── GND
                       └── GPIO 18 (ESP32)  ≈ 3.33V ✓
📄 Arduino Sketch Setup
⬇ Download .ino

Flash esp32_sketch.ino to your ESP32. It outputs JSON over USB Serial at 115200 baud every 2 seconds:

{"level":68.4, "inflow":42.1, "outflow":31.5, "temp":28.2, "ts":1234567}
  1. Open Arduino IDE → Install ESP32 board support (Espressif)
  2. Select board: ESP32 Dev Module, Upload speed: 115200
  3. Open esp32_sketch.ino → confirm TANK_HEIGHT_CM = 33 and SENSOR_OFFSET_CM = 3 (prototype values)
  4. Upload → open Serial Monitor at 115200 to verify JSON output
  5. Switch to the Live Connection tab → click Connect ESP32
